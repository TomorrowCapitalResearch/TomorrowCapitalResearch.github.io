This website

This is a static website hosted through GitHub Pages. It does not provide user accounts, an on-site contact form, advertising scripts or site analytics.

Technical requests

Hosting and network providers may process technical connection data, such as IP addresses and request details, when delivering the site. Their own terms and privacy practices apply.

Local operation

JavaScript operates the navigation and updates the copyright year. It does not set site-specific cookies or store information in browser storage. Fonts and design assets are served with the website or supplied by your device; the main company pages do not request Google Fonts or external animation services.

External platforms

Following a link to LinkedIn, GitHub, Tomorrow Library or Tomorrow Markets takes you to a separate website. Those sites have their own features and privacy practices.
